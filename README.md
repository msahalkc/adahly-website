# adahly.com

Static website for the Adahly app: landing page, privacy policy and terms.

- Plain HTML and CSS: no JavaScript, cookies, analytics or third-party requests.
- Hosted on **GitHub Pages** from the `main` branch root, custom domain `adahly.com` (see `CNAME`).
- Fonts (Bricolage Grotesque, Plus Jakarta Sans) are self-hosted under `fonts/`, SIL Open Font License.
